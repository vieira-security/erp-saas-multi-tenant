# ERP SaaS multi-tenant

ERP para lojas/restaurantes de alimentação em shopping centers no Brasil. Estado atual: **fundação do projeto** (sem funcionalidades de negócio).

## Estrutura

```
apps/            web, api, worker
packages/        contracts, validation, config, ui
docs/            documentação do produto e arquitetura
infrastructure/  IaC futura
```

## Requisitos

Node >= 22, npm >= 10.

## Comandos

```
npm install
npm run lint
npm run typecheck
npm test
```

Contribuição: veja `CLAUDE.md`.
